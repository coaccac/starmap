      두 폰 합치기: 구글 시트 한 장

      구글 시트 하나가 작은 서버 역할을 해요. 카드 등록도 서버 비용도 없어요. PC에서 한 번만 만들어 두면 두 폰이 같은 시트로 점수를 주고받고, 시트를 열면 표로도 볼 수 있어요.

      1. sheets.google.com → 빈 스프레드시트 만들기 (이름은 아무거나, 예: 별점지도)
      2. 메뉴 확장 프로그램 → Apps Script → 편집기에 있던 내용을 모두 지우고 한 것을 붙여넣기 → 저장(💾)
      3. 오른쪽 위 배포 → 새 배포 → ⚙ 유형 선택: 웹 앱 → 실행 사용자: 나, 액세스 권한: 모든 사용자 → 배포
      4. "권한 검토" → 내 구글 계정 선택 → 확인되지 않은 앱 경고가 뜨면 고급 → …(안전하지 않음)으로 이동 → 허용
      5. 나온 웹 앱 URL(…/exec)을 복사해서 설정의 "동기화 주소" 칸에 붙여넣기 → 지금 동기화
      6. 상대 폰도 설정에 같은 주소를 넣어요. "상대 폰에 연결 보내기"로 받은 링크를 열어도 돼요.
        두 폰 모두 켜자마자 연결되게 하려면 config.js의 syncUrl에 주소를 넣고 배포하면 돼요.

      주소를 아는 사람은 누구나 시트에 점수를 쓸 수 있어요. 걱정되면 Code.gs 의 TOKEN에 비밀 코드를 적고, 양쪽 폰 설정에도 같은 코드를 넣어요.
      코드를 고친 뒤에는 "배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포"를 해야 반영돼요 (URL은 그대로).
