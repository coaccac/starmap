# 내 별점 지도

내가 가본 식당만, 내 별점으로 지도에 띄우는 개인용 웹앱(PWA)이에요.

- 바탕 지도에는 가게 이름이 하나도 안 떠요. 우리가 별점 매긴 곳만 점수가 적힌 둥근 배지로 떠요.
- **각자 자기 이름으로 점수를 매겨요.** 처음 켜면 내 이름을 묻고, 이 폰에서 매기는 점수는 그 이름으로 저장돼요. 배지의 왼쪽 반원이 내 점수, 오른쪽 반원이 상대 점수 색이고 가운데 숫자는 평균이에요. 한 명만 매겼으면 반쪽이 연회색으로 비어 있어요.
- 점수가 높을수록 배지가 크고 진해져요 (2점 이하는 회색, 2.5부터 코랄이 점점 깊어짐, 평균 4.75 이상은 테두리 링, 0.5점 단위).
- **내가 아직 안 매긴 식당은 상대 점수가 안 보여요.** 지도에서는 회색 물음표 배지로 뜨고, 목록·상세·알림에도 "지은 매김"까지만 보여요. 내 점수를 저장하는 순간 상대 점수와 평균이 공개돼요. 서로 영향 안 받고 매기는 재미용이에요. (이런 곳은 ★4+ 필터를 걸어도 항상 보여요. 평균으로 숨기면 점수가 새어 나가니까요.)
- 폰 하나로 둘이 같이 매길 때는 등록 화면의 "+ 이 폰에서 다른 사람 점수도 넣기"로 상대 줄을 추가해요.
- 내 이름은 ⚙ 설정에서 바꿀 수 있어요. 바꾸면 내 점수가 전부 새 이름으로 옮겨가요.
- 목록(☰)은 구별로 묶여요. 구 이름을 누르면 접히고, "지도"를 누르면 그 구로 지도가 이동해요. 목록·상세 창은 오른쪽 위 ✕를 누르거나 아래로 쓸어내리면 닫혀요.
- 식당의 **실제 상호·위치·주소·전화는 카카오맵에서 검색해서 가져와요.** 내가 직접 치는 건 별점과 메모뿐이에요.
- **두 폰은 구글 시트 한 장으로 자동 동기화**돼요 (아래 "두 폰 합치기"). 시트가 없으면 데이터는 이 기기의 브라우저 안(localStorage)에만 있고, 설정에서 JSON 내보내기/불러오기로 옮겨요.
- 서버 없음. 정적 파일(`index.html`, `style.css`, `app.js`, `sw.js`, `sync/merge.js`)과 `vendor/`에 넣어 둔 MapLibre 5.24가 전부예요. CDN 의존 없음. 동기화 서버도 구글 시트에 붙는 작은 스크립트(`sync/Code.gs`) 하나예요.

## 처음 한 번: 카카오 키 넣기

식당 검색은 카카오맵 데이터를 써요. 무료 JavaScript 키 하나만 있으면 돼요. (앱을 처음 열고 검색을 누르면 같은 안내가 떠요.)

1. https://developers.kakao.com 로그인 → 내 애플리케이션 → 애플리케이션 추가 (이름은 아무거나)
2. 앱 → **플랫폼 키** → **JavaScript 키**의 **JavaScript SDK 도메인**에 앱 주소 등록
   - PC에서 테스트할 때: `http://localhost:8080`
   - 아이폰용으로 배포한 뒤: `https://<아이디>.github.io`
   - 주의: "웹 도메인" 메뉴는 링크용이라 거기 넣어도 지도 SDK는 안 돼요. 안 되면 `domain mismatched` 에러가 나요.
3. 앱 → **카카오맵** → **활성화 설정 ON**. 안 켜면 `disabled OPEN_MAP_AND_LOCAL service` 에러가 나요.
4. **JavaScript 키**를 복사해서 `config.js`의 `kakaoKey`에 넣기 (또는 앱의 ⚙ 설정에 붙여넣기)

JavaScript 키는 웹페이지에 노출되는 공개 키예요. 등록한 도메인에서만 동작하니 저장소에 올라가도 괜찮아요.
키 없이도 "OpenStreetMap 검색"으로 쓸 수는 있지만 한국 식당은 거의 안 나와요.

## 사용법

| 하고 싶은 것 | 방법 |
| --- | --- |
| 별점 등록 | 상단 검색창(또는 `+`) → 식당 검색 → 선택 → 별점·메모 → 저장 |
| 지금 있는 식당 바로 등록 | 검색 화면에서 **📍 내 주변** 켜기 → 가까운 식당이 거리순으로 뜸 → 선택 |
| 별점 | 내 줄이 맨 위에 있어요. 별을 누르면 1~5점, 별의 **왼쪽 절반**을 누르면 0.5점 단위, 같은 별을 다시 누르면 취소. 상대가 이미 매긴 곳은 검색 결과에 "내 점수" 표시가 뜨고, 누르면 내 점수만 보태요 |
| 이미 등록한 곳 | 검색 결과 오른쪽에 내 별점이 보여요. 누르면 상세로 가요 |
| 상세 / 수정 / 삭제 | 지도의 별을 탭 |
| 카카오맵에서 보기 | 상세 → "카카오맵에서 보기" (영업시간, 리뷰 등 최신 정보는 여기서) |
| 정보 최신화 | 상세 → "정보 새로고침": 카카오맵에서 같은 가게를 다시 찾아 이름·주소·전화를 갱신. 못 찾으면 폐업/이름 변경 가능성을 알려줘요 |
| 목록 | ☰ 버튼. 구별로 묶여서 나와요 (카카오 주소의 구 기준, 주소 없으면 경계 폴리곤으로 판정). `★4+`, `★4.5+` 칩으로 지도와 목록을 동시에 필터 |
| 내 위치 | ◎ 버튼 (https 또는 localhost에서만 동작) |
| 검색에 없는 곳 | 검색 화면 맨 아래 "지도에 직접 찍어서 등록" → 핀을 끌어 위치 지정 |
| 두 폰 맞추기 | ⚙ → 두 폰 동기화에 시트 주소 넣기. 이후엔 저장할 때마다, 앱을 다시 열 때마다 알아서 맞춰요. "지금 동기화"로 바로 맞출 수도 있어요 |
| 백업 | ⚙ → 내보내기(JSON). 복원은 불러오기(동기화와 같은 규칙으로 합쳐짐) |

## PC에서 실행해 보기

MAP 폴더에서:

```bash
python -m http.server 8080
```

브라우저에서 http://localhost:8080 열기.

## 아이폰에 설치하기 (GitHub Pages)

아이폰에서 쓰려면 https 주소가 필요해요. GitHub Pages가 무료라서 제일 간단해요.

- 저장소: https://github.com/coaccac/starmap
- 앱 주소: **https://coaccac.github.io/starmap/**

처음 한 번 (이미 해 둔 것):

1. github.com에서 새 저장소 만들기 (`starmap`, Public)
2. MAP 폴더에서 `git init` → 커밋 → `git remote add origin https://github.com/coaccac/starmap.git` → `git push -u origin main`
3. 저장소 → Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: `main` / `(root)` → Save
4. 1~2분 뒤 앱 주소가 열려요.
5. 카카오 개발자 콘솔 → 앱 → 플랫폼 키 → JavaScript 키 → JavaScript SDK 도메인에 `https://coaccac.github.io` 추가
6. 아이폰 Safari로 앱 주소 열기 → 공유 버튼 → **홈 화면에 추가**

이후 코드를 고치면 MAP 폴더에서 이것만 하면 돼요:

```bash
git add -A && git commit -m "무엇을 고쳤는지" && git push
```

아이폰에서는 앱을 완전히 닫고 다시 열면 새 버전이 받아져요.

## 두 폰 합치기 (구글 시트 동기화)

구글 시트 하나가 작은 서버 역할을 해요. 카드 등록도 서버 비용도 없고, 시트를 열면 식당 목록을 표로 볼 수도 있어요. PC에서 한 번만 만들면 돼요 (앱의 ⚙ → "시트 만드는 방법 보기"에도 같은 안내가 있어요).

1. https://sheets.google.com → 빈 스프레드시트 만들기 (이름은 아무거나, 예: 별점지도)
2. 메뉴 **확장 프로그램 → Apps Script** → 편집기에 있던 내용을 모두 지우고 [`sync/Code.gs`](sync/Code.gs) 내용을 전부 붙여넣기 → 저장(💾)
3. 오른쪽 위 **배포 → 새 배포** → ⚙ 유형 선택: **웹 앱** → 실행 사용자: **나**, 액세스 권한: **모든 사용자** → 배포
4. "권한 검토" → 내 구글 계정 선택 → 확인되지 않은 앱 경고가 뜨면 **고급 → …(안전하지 않음)으로 이동** → 허용
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사
6. 두 폰 모두 켜자마자 연결되게 하려면 `config.js`의 `syncUrl`에 넣고 배포. 아니면 각 폰의 ⚙ → "두 폰 동기화" 칸에 붙여넣기 (한쪽 폰에서 "상대 폰에 연결 보내기"로 링크를 보내도 돼요)
7. 브라우저에서 그 URL을 열어 `{"ok":true,…}`가 보이면 정상이에요

알아둘 것:

- 액세스 권한이 "모든 사용자"가 아니면 폰에서 로그인 페이지로 튕겨서 "응답이 JSON이 아니에요" 오류가 나요.
- 주소를 아는 사람은 누구나 시트에 점수를 쓸 수 있어요. 걱정되면 `Code.gs` 맨 위 `TOKEN`에 비밀 코드를 적고, 양쪽 폰 설정의 "비밀 코드"에도 같은 값을 넣어요.
- `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 해야 반영돼요 (URL은 그대로).
- 시트 탭 이름은 `식당`이고 한 줄이 식당 하나예요. 마지막 `json` 열이 원본이라 시트를 직접 고치면 다음 동기화 때 되돌아가요.

합치는 규칙 (`sync/merge.js`, 폰과 시트가 같은 코드를 써요):

- 같은 식당인지는 카카오맵 id로 봐요 (직접 찍은 곳은 앱 id).
- 식당 정보(메모·분류·방문일·위치)는 더 최근에 수정한 쪽이 남아요.
- 사람별 점수는 사람마다 따로, 더 최근에 매긴 것이 남아요. 내가 내 점수를 지우거나 이름을 바꾼 것도 상대 폰에 전해져요.
- 지우면 상대 폰에서도 지워져요. 지운 뒤에 누가 다시 등록하면 새 점수만으로 되살아나요.
- 폰이 꺼져 있거나 인터넷이 없어도 그냥 쓰면 되고, 다음에 켤 때 맞춰져요. "전체 삭제"는 이 폰만 비우고 자동 동기화를 꺼요 (시트는 그대로).

얼마나 빨리 맞춰지나:

- 내가 저장하면 1.5초 뒤에 시트로 올라가요.
- 상대 폰이 **켜져 있으면** 30초 안에 받아요. 상대도 방금 뭔가 저장했다면(같이 앉아서 매기는 중) 5초 안에 받아요. 켜져 있는 동안 시트의 "바뀜 번호"만 가볍게 물어보다가, 달라졌을 때만 전체를 받아 오는 방식이라 통신량은 작아요.
- 상대 폰이 **꺼져 있거나 다른 앱을 보고 있으면** 다음에 앱을 앞으로 가져올 때 바로 받아요. 푸시 알림처럼 깨우지는 못해요.
- 들어온 게 있으면 "새 점수 · 을지면옥: 지은 4.0"처럼 알려 줘요.

## 데이터 형식

내보내기 파일은 이런 모양이에요. 직접 편집해서 불러와도 돼요.

```json
{
  "app": "starmap",
  "version": 4,
  "places": [
    {
      "id": "m2abc123xyz",
      "kakaoId": "8123456",
      "name": "을지면옥",
      "lat": 37.5663,
      "lng": 126.9915,
      "ratings": { "민수": 5, "지은": 4 },
      "ratedAt": { "민수": 1762500000000, "지은": 1762600000000 },
      "rating": 4.5,
      "category": "냉면",
      "memo": "여름에만. 제육 꼭.",
      "address": "서울 중구 충무로 ...",
      "phone": "02-000-0000",
      "placeUrl": "http://place.map.kakao.com/8123456",
      "visitedAt": "2026-07-12",
      "createdAt": 1762500000000,
      "updatedAt": 1762500000000
    }
  ]
}
```

`ratings`는 `{ 이름: 점수 }`, `ratedAt`은 사람별로 점수를 마지막으로 바꾼 시각, `rating`은 평균이에요. 예전 형식(`rating`만 있는 데이터)을 불러오면 내 이름의 점수로 들어가요.

## 알아둘 것

- 시트 동기화를 안 쓰면 데이터는 각 기기 안에만 있어요. 그때는 내보내기 → 카톡 등으로 파일 전달 → 불러오기로 합쳐요 (동기화와 같은 규칙으로 합쳐져요).
- `tests/merge-test.html`을 열면 합치는 규칙이 폰(`merge.js`)과 시트(`Code.gs`)에서 같은지 자동으로 검사해요. 규칙을 고쳤을 때 한 번 열어 보세요.

- 지도 스타일을 바꿔도(⚙) 가게 이름(POI)과 번지수는 항상 숨겨요. 동네 이름은 남기고, 도로명·도로 번호는 기본으로 숨겨요 (⚙에서 켤 수 있어요).
- 서울 25개 구 경계와 구 이름이 기본으로 표시돼요 (`data/seoul-gu.json`, 통계청 2013 경계 단순화본, ⚙에서 끌 수 있어요).
- 바탕 지도의 지명은 한국어 우선으로 표시돼요.
- 아이폰 Safari는 오래 안 쓴 사이트의 저장 데이터를 지울 수 있어요. 홈 화면에 추가해서 쓰면 괜찮고, 가끔 내보내기로 백업해 두세요.
- 카카오 로컬 API는 개인 사용량(하루 수만 건) 안에서 무료예요.
